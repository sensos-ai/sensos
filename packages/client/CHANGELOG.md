# @sensos-ai/client

## 0.0.1

### Patch Changes

- ### New Features
  
  - **Interactive AI chat CLI:** Run agent sessions from a terminal UI with streamed responses, Markdown rendering, command handling, and support for resuming sessions.
  - **Model provider support:** Use models from OpenAI and the sensos gateway through a unified provider and model catalog.
  - **Authentication profiles:** Log in, log out, and manage credentials for supported providers, including Codex and Vercel authentication.
  - **Session management:** Create, catalog, inspect, and resume persistent chat sessions.
  - **Remote engine support:** Connect the CLI to remote engines through a negotiated, versioned transport.
  - **sensos client SDK:** Use the client package to connect to engines, interact with actors, stream responses, and transport session chats.
  - **Shared protocol contracts:** Access shared TypeScript contracts for models, registries, sessions, streams, and core engine communication.
- Updated dependencies
  - @sensos-ai/shared@0.0.1
